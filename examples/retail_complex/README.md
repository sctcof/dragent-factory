# Retail Complex Sample

多数据集复杂分析样例：

- orders.csv：720 条订单明细，含收入、成本、毛利、折扣、渠道、区域。
- customers.csv：120 个客户，含区域、客户分层、注册月份。
- products.csv：8 个商品，含品类、品牌、定价。
- marketing.csv：120 条营销投放，含月份、区域、渠道、花费、线索、新客。
- inventory.csv：48 条库存快照，含仓库、期初/期末库存、缺货天数。
- retail_complex.sqlite：同样数据的 SQLite 数据库，可在数据资产页用 sqlite:/// 连接。

推荐问题：
分析 2026 上半年收入增长质量：请结合订单、客户、商品、营销和库存数据，分至少 6 步完成趋势、贡献、毛利、投放效率、库存风险和行动建议分析。
